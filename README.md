## Development

Tools and tasks are managed with [mise](https://mise.jdx.dev).

```sh
mise install
mise run install
mise run pack
```

`mise run changelog:preview` prints the notes of the next release. Releases run in GitHub Actions (`Release` workflow), which calls `mise run release`.
