# Own Dark 001

A calm dark theme built for daily work.
Cool blue-grey UI, pastel syntax highlighting, low visual noise.

## Install

[VS Code Marketplace →](https://marketplace.visualstudio.com/items?itemName=own-themes.own-dark-001)

## Modern UI editor tabs

In VS Code's Modern UI with the default `connected` tab style, the active tab takes its color from `editor.background`. VS Code ignores `modernEditorTab.*` colors from a theme file in this mode, so set it in your `settings.json`:

```json
"workbench.colorCustomizations": {
  "[own-dark-001]": {
    "modernEditorTab.activeBackground": "#393c40"
  }
}
```
